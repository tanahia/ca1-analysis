
#Kerry Community Sports Facility Service

##Project Overview

This project analyses the requirements for a community sports facility service coordinated by Kerry Community Sports Partnership. The service manages bookings for sports pitches, halls, training rooms and shared equipment across multiple sites.

The project focuses on identifying stakeholder needs, modelling the system domain, documenting requirements and describing expected system behaviour. It addresses challenges such as facility availability, conflicting bookings, recurring requests, equipment allocation, setup and reset times, maintenance restrictions and operational decisions.

Where the scenario does not define a clear policy, uncertainties, assumptions and questions requiring stakeholder clarification are documented rather than treated as confirmed requirements.

## Folder Descriptions

- **diagrams/** – Contains the PlantUML diagrams, including the user model and domain model.
- **features/** – Contains Gherkin feature files.
- **References/** – Contains AI reflection document.
- **report/** – Contains the project report.
- **requirements/** – Contains the project functional and non-functional requirements document.
- **README.md** – Provides an overview of the repository and explains its structure.
